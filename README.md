## How I document progress

Each meaningful update should include the date, the concept practiced, a link to code or notes when available, what I understood, what I struggled with, and the next step. I will mark work as completed only when I can explain and reproduce it.

Security experiments belong in systems I own, training labs, or environments where I have explicit permission.
